# tgrefhub

A lightweight reference hub for Telegram — a place to collect and browse links, resources, and references related to Telegram bots, libraries, and integrations.

Live demo: https://tgrefhub.vercel.app

> Note: This repository is private. If you want to make it public, change the repository visibility in the repository settings.

## What this repository contains

- Frontend built with JavaScript (see src/)
- Styling with CSS
- Site deployed to Vercel

## Getting started (development)

1. Clone the repo

   git clone https://github.com/hackerdy/tgrefhub.git
   cd tgrefhub

2. Install dependencies

   npm install

3. Start the dev server

   npm run dev

4. Open the app

   Visit http://localhost:3000 (or the port shown in the terminal).

## Build for production

   npm run build
   npm run start
